# Rekara Creative

Website company profile Rekara Creative (satu file `index.html`, tanpa build).

## Mengedit
Buka `index.html`, lalu cari bagian `KONFIGURASI` dan `DATA` di dalam tag `<script>` (paling bawah) untuk mengganti nomor WhatsApp, email, Instagram, paket, FAQ, dan testimoni.

## Hosting
GitHub Pages: Settings > Pages > Deploy from a branch > `main` / `(root)`.
